Anmelden

Zum Bearbeiten brauchst du einen GitHub-Zugangsschlüssel, der nur für dieses Repository gilt.

So erstellst du den Zugangsschlüssel (einmalig)
  1. Öffne auf github.com: Profilbild › Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Name: z. B. „Lernmatrix“. Ablaufdatum: bis nach dem Abitur.
  3. Repository access: Only select repositories › wn-q-phase.
  4. Permissions › Repository permissions › Contents: Read and write.
  5. Generate token, den Schlüssel kopieren und hier einfügen. Gib ihn an niemanden weiter.
